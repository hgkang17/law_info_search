# 법령 AI 검토 (실험)

국가법령정보 통합검색에 LLM 검토 기능을 붙인 실험용 갈래다. 본체
저장소와 따로 두어, 여기서 무엇이 깨지든 본체는 영향을 받지 않는다.

## 지금 되는 것

왼쪽 메뉴 맨 아래 **AI 검토**를 누르면 나온다.

1. 다른 화면에서 법령을 열어 둔다.
2. AI 검토 화면에서 **현재 본문 가져오기**를 누른다.
   - 본문에서 일부만 드래그해 두었으면 그 부분만 가져온다.
   - 아무것도 선택하지 않았으면 화면에 떠 있는 본문을 통째로 가져온다.
3. 질문을 쓰고 **질문하기**를 누른다. 답이 조각으로 흘러나온다.

## 준비

```
pip install -r requirements.txt
```

화면 위쪽 **API 인증키**에는 국가법령정보 공동활용 OC 키를 넣는다.
Claude Code와 ChatGPT(Codex)는 이 키를 프로그램이 띄우는 법령검색 MCP
서버에만 전달한다.

- **Claude Code**: Claude Code CLI 설치 후 터미널에서 로그인한다.
- **ChatGPT (Codex)**: Codex 데스크톱 앱 또는 CLI를 설치하고 ChatGPT
  계정으로 로그인한다. 프로그램은 공식 `codex app-server` 인터페이스로
  대화를 이어 간다.
- **Gemini**: 모델 제공자용 Gemini API 키도 AI 화면의 별도 API 키 칸에
  입력한다. 화면의 **키 발급** 단추가 발급 페이지를 연다.

키는 이 컴퓨터의 사용자 설정(QSettings)에만 저장되고 저장소에는
올라가지 않는다. Claude/Codex에 넘기는 OC 키는 명령줄에 넣지 않는다.

## 모델 목록은 받아 온다

모델 이름은 제공자가 예고 없이 갈아 치운다. 처음에는 `gemini-2.5-flash`를
코드에 박아 두었다가 "신규 사용자에게는 더 이상 제공되지 않는다"는 404를
맞았다. 그래서 지금은 **목록 새로고침** 단추로 Google에 직접 물어본다.

키를 넣기 전에는 이름이 `-latest`로 끝나는 별칭만 보인다. 이 별칭은
Google이 최신 세대로 계속 옮겨 주므로 박아 두어도 깨지지 않는다.

무료 한도는 모델과 시기에 따라 다르고 API로는 알 수 없다. 정확한 값은
발급 페이지에서 확인한다.

## 본문을 통째로 넣지 말 것

법령 전문은 수십만 토큰이다. 무료 한도는 요청 횟수로 세지만, 유료로
넘어가면 요금이 크게 붙고 무엇보다 **답이 흐려진다**. 관련 조문만
넣는 쪽이 싸고 정확하다. **토큰 세보기**로 보내기 전에 크기를 확인할
수 있다.

## 구조

제공자를 추가할 때 화면은 고치지 않아도 되게 나눠 두었다.

```
llm/
├─ base.py              LlmProvider 인터페이스 + 법령용 시스템 프롬프트
├─ claude_code.py       Claude Code CLI 대화 + 법령 MCP
├─ codex_app_server.py  ChatGPT/Codex app-server 대화 + 법령 MCP
├─ desktop_mcp.py       소스/exe 공용 MCP 실행 명령
├─ gemini.py            Gemini 구현
└─ __init__.py          PROVIDERS 목록

ui/tabs/ai_review.py   화면. LlmProvider만 알고 구체 제공자는 모른다
```

답을 받는 일은 별도 스레드에서 한다. 화면 스레드에서 부르면 답이 오는
동안 창이 얼어붙는다.

Claude와 Codex 대화는 세션을 유지해 후속 질문이 이어진다. Codex 대화는
로컬 thread 기록으로 남아 같은 Codex 호스트의 데스크톱 앱에서도 확인할
수 있다. 프로그램을 종료하거나 **새 대화**를 누르면 실행 중인 자식
프로세스도 닫는다.
