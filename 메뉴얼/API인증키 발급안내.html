법제처 API 인증키 발급 안내

이 프로그램은 법제처 국가법령정보 공동활용 OPEN API로 법령을 불러옵니다. 인증키는 무료이며, 아래 순서대로 하시면 됩니다. 사이트 주소는 open.law.go.kr 입니다.

먼저 알아 두실 것
인증키(OC)는 본인이 직접 정하는 아이디 형태의 값입니다. 가입 신청서에 원하는 값을 적어 넣으면 그것이 그대로 인증키가 됩니다.

1국가법령정보 공동활용 사이트 접속

open.law.go.kr에 들어가서 오른쪽 위 로그인을 누릅니다.

2사용자 가입

계정이 없으면 로그인 화면 아래쪽 사용자 가입을 누릅니다. 이미 계정이 있으면 로그인한 뒤 3번으로 넘어가시면 됩니다.

3OPEN API 신청

가입 서식에서 아래 항목을 꼭 채웁니다.

  • openAPI를 신청합니다 체크
  • API인증키(OC) — 쓰고 싶은 값을 적고 중복확인을 누릅니다. 이 값이 곧 인증키입니다. (영문ㆍ숫자 조합, 예: 본인 아이디)
  • 도메인주소 — 홈페이지가 없으면 도메인 없음을 고릅니다.
  • 활용 목적 — 어떤 일에 쓸 것인지 적습니다. 내용이 비어 있거나 공란이면 승인이 취소될 수 있습니다.
  • 공동활용 법령종류 — 반드시 전체선택을 합니다. 이 프로그램은 법령ㆍ행정규칙ㆍ자치법규ㆍ별표서식과 판례ㆍ해석례ㆍ 질의회신을 모두 불러오므로, 일부만 고르면 고르지 않은 쪽은 검색이 되지 않습니다.

4프로그램에 인증키 입력

발급받은 인증키를 프로그램 오른쪽 위 법제처 API 인증키 칸에 적고, 옆의 저장을 체크하면 다음에 켤 때 다시 넣지 않아도 됩니다.

  • 인증키는 기본으로 가려집니다. 표시를 누르면 잠깐 확인할 수 있습니다.
  • 신청한 값이 기억나지 않으면 사이트의 마이페이지 → API인증키관리에서 확인할 수 있습니다.
인증키 발급과 승인은 법제처에서 처리합니다. 신청 직후 바로 쓰지 못할 수도 있으니, 검색이 되지 않으면 잠시 뒤 다시 시도해 주세요.
