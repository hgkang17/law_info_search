제미나이 API 키 발급 안내

이 프로그램에서 Gemini를 사용하려면 Google AI Studio의 API 키가 필요합니다. Google 계정으로 로그인한 뒤 아래 순서대로 진행하세요.

API 키는 비밀번호처럼 관리하세요.
다른 사람에게 보내거나 인터넷·문서·화면 캡처에 공개하지 마세요. 발급 자체에는 비용이 없지만, 무료 한도를 넘거나 유료 결제를 연결하면 사용량에 따라 비용이 발생할 수 있습니다.

1Google AI Studio의 API 키 화면 열기

아래 버튼으로 Google AI Studio의 API 키 화면을 열고 Google 계정으로 로그인합니다. 화면 오른쪽 위의 API 키 만들기를 누릅니다.

Google AI Studio 열기

2키 이름과 프로젝트 선택

새 키 만들기 창에서 다음 항목을 정한 뒤 키 만들기를 누릅니다.

  • 키 이름 지정 — 알아보기 쉬운 이름을 적습니다. 예: Gemini API Key
  • 가져온 프로젝트 선택 — 사용할 Google Cloud 프로젝트를 고릅니다. 처음 사용하는 계정은 기본 프로젝트와 키가 자동으로 만들어질 수도 있습니다.

기존 Google Cloud 프로젝트가 목록에 없다면 왼쪽의 프로젝트 → 프로젝트 가져오기에서 먼저 가져오세요.

3생성된 API 키 복사

키가 만들어지면 목록에 새 항목이 나타납니다. 해당 키의 복사 아이콘을 누르거나 키 이름을 열어 키 복사를 누릅니다.

  • 복사한 키 전체를 메신저, 이메일 또는 메모 문서에 따로 남기지 마세요.
  • 키가 노출되었다면 AI Studio에서 기존 키를 삭제하고 새 키를 만드세요.

4프로그램에 API 키 입력

프로그램 왼쪽 메뉴에서 AI 에이전트를 열고, 제공자를 Gemini로 선택합니다. 위쪽의 Gemini API 설정을 누른 뒤 복사한 키를 Gemini API 키 칸에 붙여 넣고 저장하고 닫기를 누릅니다.

  • 갱신 — 사용할 수 있는 모델 목록을 다시 불러옵니다.
  • 내 사용량 확인 — AI Studio에서 사용량과 한도를 확인합니다.
Google의 화면·요금·무료 한도는 변경될 수 있습니다. 최신 내용은 Google 공식 API 키 안내와 AI Studio 사용량 화면에서 확인하세요.
