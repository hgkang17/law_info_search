# 프로그램 안에서 AI와 법령 검토하기

국가법령정보 통합검색 왼쪽 메뉴 맨 아래 **AI 검토**를 누르면 대화창이
열린다. 여기서 법령을 놓고 AI와 주고받을 수 있다.

```
이 조문이랑 시행령 중에 뭐가 우선이야?
농지전용허가 대상인지 판단하는 기준 조문 찾아줘
방금 그 조문, 개정 전이랑 뭐가 달라졌어?
```

AI가 답할 때 **기억으로 답하지 않는다.** 프로그램이 법제처 자료를
직접 찾아 읽게 해 두었고, 답에 나오는 조문은 눌러서 원문으로 갈 수
있다.

## 돈이 얼마나 드나

**이미 쓰고 있는 Claude나 ChatGPT 구독을 그대로 쓴다. 추가 요금이
붙지 않는다.**

| 고르는 AI | 필요한 것 | 요금 |
|---|---|---|
| **Claude Code** | Claude 구독 (Pro/Max) | **추가 요금 없음** |
| **ChatGPT (Codex)** | ChatGPT 구독 | **추가 요금 없음** |
| Gemini | Google API 키 | **쓴 만큼 과금** (무료 한도 있음) |

앞의 둘은 이 컴퓨터에 설치된 CLI가 **이미 로그인해 둔 구독 계정**으로
돈다. 프로그램이 별도 API 키를 받지 않는다. 그래서 청구서가 새로
생기지 않고, 쓰는 만큼 해당 구독의 사용량만 줄어든다.

Gemini는 다르다. 이건 Google API 키를 직접 넣는 방식이라 한도를
넘으면 과금될 수 있다. 구독으로 쓰고 싶으면 **Claude Code나
ChatGPT(Codex)를 고른다.**

법제처 국가법령정보 API는 어느 쪽을 고르든 무료다.

---

## 준비 1 — 법제처 OC 인증키

어느 AI를 쓰든 이건 있어야 한다. AI가 법령을 찾아 읽는 통로다.

1. https://open.law.go.kr 접속
2. 회원가입 후 **OPEN API → 활용신청**
3. 발급받은 OC 인증키를 프로그램 **위쪽 "API 인증키"** 칸에 붙여 넣는다
4. 옆의 저장 체크를 켜면 다음에 다시 넣지 않아도 된다

키가 없으면 AI가 법령을 못 찾는다. 화면에도 "법제처 API 인증키가
있어야 조문을 열 수 있습니다"라고 뜬다.

## 준비 2 — Claude 또는 ChatGPT 붙이기

둘 중 **하나만** 하면 된다. 둘 다 해 두고 골라 쓸 수도 있다.

### Claude를 쓰는 경우

Claude Pro나 Max 구독이 있어야 한다.

1. **Node.js 설치** — https://nodejs.org 에서 LTS 버전을 받아 설치한다.
   이미 있으면 넘어간다.

2. **Claude Code 설치** — 시작 메뉴에서 `명령 프롬프트`나
   `PowerShell`을 열고 아래를 붙여 넣는다.

   ```
   npm install -g @anthropic-ai/claude-code
   ```

3. **로그인** — 같은 창에서 아래를 실행하면 브라우저가 열린다.
   Claude 계정으로 로그인한다.

   ```
   claude
   ```

   로그인이 끝나면 `/exit`를 입력해 빠져나온다.

4. 프로그램의 AI 검토 화면에서 제공자를 **Claude Code**로 고른다.

### ChatGPT를 쓰는 경우

ChatGPT 구독(Plus 등)이 있어야 한다.

1. **Node.js 설치** — 위와 같다.

2. **Codex 설치**

   ```
   npm install -g @openai/codex
   ```

3. **로그인** — 아래를 실행하고 ChatGPT 계정으로 로그인한다.

   ```
   codex
   ```

   ChatGPT 데스크톱 앱을 이미 쓰고 있다면 그 로그인을 그대로 쓴다.

4. 프로그램의 AI 검토 화면에서 제공자를 **ChatGPT (Codex)** 로 고른다.

### MCP 설정은 따로 할 것이 없다

법령검색 도구(MCP)는 **프로그램이 대화할 때마다 알아서 붙여 준다.**
`claude_desktop_config.json` 같은 설정 파일을 열 일이 없고, 이미 쓰고
있는 Claude나 ChatGPT의 다른 설정도 건드리지 않는다.

이 대화에만 붙였다가 끝나면 사라지는 방식이라, AI가 볼 수 있는 것은
법령 검색 도구 세 개뿐이다. 컴퓨터의 파일이나 폴더에는 접근하지
못한다.

---

## 쓰는 법

1. 다른 화면에서 법령을 열어 둔다.
2. AI 검토 화면에서 **현재 본문 가져오기**를 누른다.
   - 본문에서 일부만 드래그해 두었으면 **그 부분만** 가져온다.
   - 아무것도 선택하지 않았으면 화면의 본문을 통째로 가져온다.
3. 질문을 쓰고 **보내기**를 누른다.

본문을 안 가져와도 된다. 그냥 물어보면 AI가 검색해서 찾아 읽는다.

### 화면의 단추들

| 단추 | 하는 일 |
|---|---|
| **보내기** | 질문을 보낸다 |
| **중지** | 답하는 중에 끊는다 |
| **새 대화** | 앞의 대화를 지우고 처음부터 시작한다 |
| **갱신** | 고를 수 있는 모델 목록을 다시 받아 온다 |
| **☆ 즐겨찾기에 추가** | 답에서 AI가 실제로 읽은 법령을 바로 저장한다 |

### 모델 고르기

| Claude Code | ChatGPT (Codex) |
|---|---|
| Opus — 가장 정확, 가장 느림 | GPT-5.6 Sol — 가장 어려운 검토 |
| Sonnet — 균형 | GPT-5.6 Terra — 균형 |
| Haiku — 가장 빠름 | GPT-5.6 Luna — 빠른 검토 |

잘 모르겠으면 **기본 모델**로 둔다. 답이 부실하면 위쪽 모델로 올린다.

### 조문 링크

답 안의 조문 이름은 눌러서 프로그램의 본문 화면으로 바로 넘어갈 수
있다. AI가 지어낸 게 아니라 실제로 읽은 조문이라는 뜻이기도 하다.

---

## 안 될 때

### "claude 명령을 찾지 못했습니다"

Claude Code가 안 깔렸거나, 깔렸는데 프로그램이 못 찾는 경우다.

1. 명령 프롬프트에서 `claude --version`을 쳐 본다. 버전이 나오면 설치는
   된 것이다.
2. 버전이 나오는데도 프로그램에서 안 되면 **프로그램을 껐다 켠다.**
   설치 후 PATH가 갱신되려면 프로그램을 다시 시작해야 한다.
3. 아무것도 안 나오면 설치가 안 된 것이다. 준비 2를 다시 한다.

### "codex 명령을 찾지 못했습니다"

같은 문제다. `codex --version`으로 확인하고 프로그램을 재시작한다.

### 로그인은 했는데 답이 안 온다

명령 프롬프트에서 `claude`(또는 `codex`)를 직접 실행해 아무거나
물어본다. 거기서도 안 되면 CLI 쪽 로그인 문제이므로 다시 로그인한다.
거기서는 되는데 프로그램에서만 안 되면 프로그램을 재시작한다.

### "300초 안에 응답이 오지 않아 중단했습니다"

질문이 너무 넓어서 AI가 검색을 계속 도는 경우다. 범위를 좁혀 다시
묻는다. ("법령 전체 검토해 줘" → "제3조와 시행령 제5조 관계만
봐 줘")

### 답은 오는데 법령을 못 찾는다

OC 인증키 문제다. 준비 1을 다시 확인한다. 키를 안 넣어도 AI는 답을
하지만, 화면에 붙여 넣은 본문만 보고 답하게 된다.

### 검은 창이 잠깐 떴다 사라진다

정상이다. AI를 부르는 순간이다.

## 본문을 통째로 넣지 말 것

법령 전문은 분량이 매우 크다. 전부 넣으면 사용량이 빨리 닳고
무엇보다 **답이 흐려진다.** 관련 조문만 넣는 쪽이 정확하다.

## Gemini를 쓰는 경우

구독 없이 시험만 해 보고 싶을 때 쓴다.

1. AI 검토 화면에서 제공자를 **Gemini**로 고른다.
2. 화면에 나타나는 **API 키** 칸 옆 **발급** 단추를 누르면 발급
   페이지가 열린다.
3. 받은 키를 그 칸에 넣는다.

이 키는 앞의 법제처 OC 인증키와 **다른 것**이다. 두 개를 각각 넣어야
한다. 무료 한도를 넘으면 과금될 수 있으니 사용량을 확인하며 쓴다.

## 키는 어디에 저장되나

인증키는 **이 컴퓨터의 Windows 사용자 설정에만** 저장된다. 어디로도
전송되지 않는다. OC 인증키는 AI에게 보이지도 않는다 — 프로그램이
법령검색 도구에만 따로 넘긴다.
