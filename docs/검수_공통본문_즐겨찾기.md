# 본문ㆍ링크ㆍ즐겨찾기 구조 검수 (2026-09-10)

## 앞으로 수정할 공통 경계

```text
API별 원문 → 종류별 파서 → normalize_legal_body → legal_body_to_html
                                                 ├─ 전문
                                                 ├─ 조문검색
                                                 ├─ 조문ㆍ문서 팝업
                                                 └─ 3단비교 셀
저장된 QTextDocument → apply_annex_links → 같은 별표 번호ㆍ분류ㆍ주소 규칙
```

- `utils/legal_body.py`: 별표 번호 패턴ㆍ라벨ㆍ주소ㆍHTML 링크ㆍ저장 문서 보강.
  전문에 실제 별표 목록이 있으면 같은 인용을 `annexopen:목록번호`로 연결한다.
  조문검색ㆍ팝업처럼 목록이 없는 곳은 `annexref` 검색 링크를 사용한다.
- `utils/parsing.py:normalize_legal_body`: 문서 종류와 번호체계를 구분해 기존
  정규화ㆍ세부항목 분리를 순서대로 적용한다. 이번 작업에서 정규식 자체의
  인식 범위는 넓히지 않았다. 법령 전문 파서도 `law_article_text`를 사용한다.
- 법령 조문은 `get_law_article`의 `eflawjosub`, 행정규칙 조문은 전문에서
  추출하는 기존 차이를 유지한다. 원문 API가 다른 것과 화면 처리 중복은
  별개의 문제다. API 호출을 하나의 응답 형식으로 억지 통합하지 않았다.
- 새 법령 화면 HTML은 `LAW_RENDER_SNAPSHOT_VERSION=21`, 조문 팝업 캐시는
  `LAW_REFERENCE_CACHE_SCHEMA=6`으로 구분한다. 조문검색의 구버전 저장 HTML은
  글자ㆍ메모 위치를 바꾸지 않고 별표 링크를 보강한다.
- 즐겨찾기는 폴더도 `favorite_order`를 저장한다. 오래된 폴더 데이터는
  기존 폴더 우선 순서를 유지하며 이후 사용자가 배치한 순서를 기록한다.

## 남은 검수 범위와 제약

1. **위임 링크의 비동기 수명**: 전문은 3단비교 자료를 미리 받지만,
   `_popup_authority_links`는 이미 메모리에 있는 3단비교 자료를 사용한다.
   처음부터 조문검색ㆍ팝업만 열었을 때, 자료가 나중에 도착했을 때의
   `대통령령으로 정한다` 같은 조번호 없는 위임 문구는 별도 검수가 필요하다.
   다음 구조 개선은 법령ID별 자료 요청ㆍ중복 억제ㆍ도착 알림을 화면 밖의
   공통 서비스로 옮기는 것이다. 응답 대상과 현재 화면을 구분하는 요청 식별도
   함께 보존해야 한다.
2. **행정규칙ㆍ자치법규 자기 조문 참조**: 법령 조문 API에 다른 종류의 ID를
   전달하면 안 된다. 문서 팝업도 전문과 같이 자기 조문을 임의로 법령 API에
   연결하지 않는다. 별도 조문 탐색기를 만들 때 번호체계와 대상 종류를 포함한
   참조 모델이 필요하다.
3. **과거 HTML만 있는 저장내역**: 기존 3단비교ㆍ팝업 저장내역에는 원문 payload가
   없는 항목도 있다. 이를 모두 최신 줄바꿈으로 자동 재생성한다고 보장하지
   않는다. 메모ㆍ수동 서식의 문자 위치를 보호하는 이관 설계가 필요하다.
4. **실자료 예외**: 특정 자치법규ㆍ행정규칙의 번호 오분리, 다른 법령의 별표를
   함께 인용하는 문장, 목별 위임 중복은 해당 원문을 재현 자료로 추가해야 한다.
   이번 테스트 통과를 모든 법령ㆍ별표 API의 실조회 성공으로 해석하면 안 된다.
5. **즐겨찾기 재구성 비용ㆍ보기 상태**: 공용 `changed` 신호가 본문 저장과
   즐겨찾기 변경을 구분하지 않아 전체 트리를 자주 다시 만든다. 수동 순서
   유실은 수정했지만 많은 폴더에서 선택ㆍ스크롤 보존 및 변경 구분 신호 도입은
   추가 대상이다. 프로젝트별 파일 쓰기를 하나의 트랜잭션으로 처리하지도 않는다.
