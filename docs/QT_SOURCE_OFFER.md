# Qt/PySide6 대응 소스 제공 안내

이 프로그램의 Windows EXE에는 LGPL v3로 배포되는 Qt for Python(PySide6)과
Qt 라이브러리가 포함됩니다.

각 GitHub Release에 실제로 포함된 LGPL 구성 요소의 완전한 대응 소스 코드,
적용한 수정 사항(현재 없음), 그리고 수정한 라이브러리로 프로그램을 다시
빌드하고 실행하는 데 필요한 정보를 요청할 수 있습니다.

- 요청처: `hgkang17@naver.com`
- 요청 시 필요한 정보: 프로그램 버전 또는 GitHub Release 태그
- 제공 비용: 전자 파일 제공은 무료이며, 물리 매체가 필요한 경우 실제 복제와
  배송에 드는 합리적인 비용만 청구할 수 있습니다.
- 유효기간: 해당 EXE Release를 마지막으로 배포한 날부터 최소 3년

프로그램 자체 소스와 PyInstaller 빌드 설정은 각 Release의 소스 아카이브와
이 저장소에서 확인할 수 있습니다. LGPL v3 및 GPL v3 전문은 `licenses/`
폴더와 프로그램의 `프로그램 정보 → 라이선스 원문 보기`에 포함됩니다.
