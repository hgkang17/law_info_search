# 국가법령정보 통합검색 프로그램

국가법령정보 공동활용 API의 법령·행정규칙·자치법규, 별표·서식, 중앙부처 질의회신, 법령해석례, 판례와 키워드검색 기능을 Qt 데스크톱 UI로 제공합니다.

## 실행

`국가법령정보 통합검색.bat`을 더블클릭합니다. 실행기는 `pythonw.exe`를 사용하므로 CMD 창이 계속 열려 있지 않습니다.

상단 `API 인증키`에 인증키를 입력합니다. `API 저장`을 체크하면 현재 Windows 사용자의 앱 설정에 보관되며, 체크를 해제하면 저장값이 삭제됩니다.

## 자동 업데이트

배포용 EXE는 공개 GitHub 저장소의 최신 정식 Release를 확인합니다. 새 버전이
있으면 알림을 표시하며, 사용자가 승인한 경우에만 EXE를 다운로드하고 파일
크기와 SHA-256을 검증한 뒤 현재 EXE를 교체합니다. 릴리스 방법은
[`docs/GITHUB_RELEASES_UPDATE.md`](docs/GITHUB_RELEASES_UPDATE.md)를 참고합니다.

## 주요 기능

- 39개 기관 중 하나를 선택하거나 전체 기관 통합 검색
- 왼쪽 세로 메뉴는 다섯 개 검색 메뉴를 위쪽에 배치하고, `열람내역`은 별도 금색 버튼으로 패널 맨 아래에 고정
- `법령검색`에서 법령·행정규칙·자치법규와 각 별표·서식 6개 중분류 탭 선택 검색
- 법령(`law`→`eflaw`), 행정규칙(`admrul`), 자치법규(`ordin`) 목록 및 전체 본문 조회
- 법령 본문의 `「법령명」 제○조제○항제○호○목` 인용을 자동 링크로 만들고, 클릭 시 현행법령 조항목 API(`eflawjosub`) 결과를 클릭 위치 아래 팝업으로 표시
- 조항목 팝업은 고정 후 제목줄이나 화살표 줄로 이동하고 네 변·네 모서리에서 크기를 조절할 수 있으며, 조회한 조항목은 본문 하단의 좁은 `법령명/조항호목` 두 줄 이력 탭에서 다시 열 수 있음
- 법령검색 `통합검색`에서 법령·행정규칙·자치법규와 각 별표·서식을 한 번에 조회
- 법령검색·키워드검색·중앙부처 질의회신·법령해석례 본문은 같은 제목·구획·글꼴 스타일을 사용하고, 구분·ID·관련 기관 등 기본정보를 한 줄에 최대 3개 항목씩 배치
- 모든 본문·조항 팝업·3단비교 내용에 `맑은 고딕` 보통(400) 글꼴 적용. 제목급과 강조 표시는 기존 굵기 유지
- 일반 법령 본문 조회 시 편·장·절·관과 조문을 모은 왼쪽 목차 트리 및 클릭 바로가기 제공
- 법령 본문의 각 조문 오른쪽에는 `3단비교` 버튼만 표시하고, 최초 한 번 받은 위임조문 API 자료를 재사용해 해당 조문의 법률·시행령·시행규칙을 3열 팝업으로 비교. 시행령 조문의 `법 제○조제○항·제○호` 근거와 본문 위치를 맞춰 법률 문장 안의 `대통령령`을 해당 시행령 조문 하나에 직접 연결하고, 시행령 문장 안의 `소관부처령`도 같은 방식으로 연결. 같은 항·호에 복수 조문이 대응할 때만 클릭 위치에 선택목록을 표시. 시행령에서 부령으로 내려갈 때는 부령 본문이 `영 제○조`를 명시한 대응관계만 우선 연결. 조회한 3단비교는 본문 하단 기록 탭에 남아 다시 열 수 있음
- 저장 법률에는 완성 HTML·목차·하위법령 링크의 화면 스냅샷만 보관하고 전체 3단비교 원문은 디스크에 저장하지 않음. 즐겨찾기는 크게보기 폭을 먼저 확정한 뒤 한 번만 그려 좁은 본문이 순간적으로 넓어지는 현상을 방지
- 조문 번호·조문명 검색, 일치 개수 표시 및 이전·다음 조문 바로가기 제공
- 목차에서 조문으로 이동하면 해당 조문 시작부터 다음 목차 항목 직전까지 옅은 배경으로 전체 범위를 표시
- 본문에서 `Ctrl+F`를 누르면 현재 스크롤 위치를 유지한 채 본문 검색창으로 이동·검색어 전체 선택하고 활성 검색창을 연노랑 음영으로 강조하며, 검색창에서 본문을 다시 클릭해도 보던 위치 유지
- `본문`의 두 줄 문서 탭으로 여러 법령·행정규칙·자치법규 및 별표 링크를 동시에 열어두고 전환 가능
- 문서 탭별 본문·조문 목차·내부 검색어·스크롤 위치 유지, 같은 문서 중복 탭 방지
- API로 열어 본 법령 원문과 키워드 조문·연관법령·질의회신·해석례·판례 본문을 실행 프로그램의 `# law 캐시/저장내역` 폴더에 저장하고, `열람내역`에서 유형별로 모아 API 호출 없이 원래 검색 화면에 즉시 다시 열기
- 법령·행정규칙·자치법규 검색 결과의 `저장` 열은 저장 가능한 모든 본문에 체크박스를 표시. 빈 체크박스를 누르거나 본문을 열면 자동 저장하고, 저장 셀의 불필요한 선택 영역은 표시하지 않으며, 체크 해제 시 API에서 다시 받아 저장본 갱신
- 키워드 직접검색·연관법령·중앙부처 질의회신·법령해석례·판례검색 결과에도 포커스 사각형 없이 체크만 보이는 `저장` 열을 제공. 키워드 결과는 `조문·별표` 다음 `법령·행정규칙명` 순으로 표시하고 행 클릭 전후의 가로 스크롤 위치를 유지. 상세 본문이나 조문을 처음 열면 로컬 스냅샷으로 자동 저장하고, 이후에는 API 호출 없이 저장본을 표시하며 체크 해제 시 해당 API 결과로 갱신
- 법령 검색 결과에서는 내부 조회에만 사용하는 ID 열을 숨겨 명칭 중심으로 표시
- `검색 결과`와 `본문`의 글자 크기를 위아래 버튼으로 7~18pt 범위에서 0.5pt씩 조절하고 선택값을 프로그램 설정에 저장
- 저장 목록에서 법령명 검색, 시행일·저장일시 확인, 저장 폴더 바로 열기 지원
- `본문` 제목·위아래 화살표가 표시되는 글자 크기·음영색/글자색 팔레트를 여백과 함께 한 줄에 배치. `선택초기화`와 `전체초기화`는 팔레트 높이에 맞춰 위아래로 묶고 같은 높이의 `메모`, 도구줄 끝에는 글자를 키운 두 줄 `크게 보기`를 배치. 상세 조회 단추가 필요한 검색 화면은 그 옆에 `본문 조회`를 표시하고, 사례 검색의 분할 본문은 작은 `×`를 표시. 전체 색상 초기화 후에도 메모의 노란 음영은 복원
- 본문에서 선택한 글자색을 `Ctrl+G` 초록, `Ctrl+R` 빨강, `Ctrl+K` 검정, `Ctrl+W` 흰색, `Ctrl+Y` 노랑, `Ctrl+B` 파랑으로 빠르게 지정하며 색상 버튼 툴팁에 단축키 표시
- 열람내역에 저장된 법령의 음영·글자색 범위를 로컬 저장본에 즉시 기록하여 프로그램 재실행 후에도 복원
- 즐겨찾기는 `법령검색·별표·서식·키워드검색·중앙부처 질의회신·법령해석례·판례검색`의 고정된 6개 가로 카드 배치를 유지. 각 카드 제목 오른쪽 `+`로 사용자 폴더와 하위 폴더를 만들고, 폴더 우클릭 메뉴에서 이름 변경·삭제. 사용자 폴더에만 폴더 아이콘을 표시하고 법령 항목에는 아이콘이나 선택 모서리를 표시하지 않음. `Ctrl` 개별 선택·`Shift` 범위 선택 후 여러 항목을 함께 드래그 이동하고 순서를 저장
- 본문을 드래그해 선택한 뒤 `메모` 버튼으로 노란 메모지 창에서 여러 줄 메모 작성, 선택 문구의 노란 음영·마우스 툴팁·본문 오른쪽 메모 띠지 표시 및 프로그램 재실행 후 복원. 가까운 띠지는 자동으로 벌어지며 폭 변화 없이 hover·눌림·선택 상태를 색으로 구분
- `본문 크게 보기`로 상단 검색 UI와 왼쪽 결과를 접어 본문을 창 전체로 확대 (`F11` 전환, `Esc` 복귀, 제목 더블클릭 지원)
- 법령 별표(`licbyl`)는 `별표·서식명(search=1)`·`해당 법령명(search=2)`·`별표 본문(search=3)` 검색범위를 제공하고 기본값은 해당 법령명으로 설정. 행정규칙 별표(`admbyl`)와 자치법규 별표(`ordinbyl`)를 포함해 원본·PDF 링크 표시
- PDF 미리보기 배율은 퍼센트를 직접 입력하거나 위·아래 버튼과 Ctrl+휠로 5%씩 조절(20~300%)
- 법령해석례(`target=expc`) 목록 및 상세 본문 조회
- 판례(`target=prec`) 목록 및 판시사항·판결요지·참조조문·참조판례·판례내용 조회
- `키워드검색` 하위의 직접검색(`target=aiSearch`)과 연관법령(`target=aiRltLs`) 탭
- 직접검색 조문내용의 법령 링크는 현재 검색 내용을 유지한 채 기본 웹 브라우저에서 열기
- 연관법령 결과를 선택하면 법령은 조항목 API로, 행정규칙은 본문 API로 해당 조문을 자동 조회하고 같은 항목 재선택 시 메모리 저장 결과를 즉시 표시
- 법령검색·키워드검색의 하위 탭은 상단 대분류보다 작고 파란 선택 색상을 사용해 계층을 구분
- XML 본문이 없는 국세청 판례는 웹 원문 열기
- API 인증키 전용 입력칸, 테두리가 보이는 저장 체크박스 및 선택적 저장
- 안건명 또는 본문 검색
- 빈 검색창으로 시작하며, 최근 검색어 10개를 모든 검색 탭에서 공유·저장하고 한 줄에 5개씩 두 줄로 배치. 긴 검색어는 버튼 안에서 두 줄로 표시하며 `초기화` 제공
- 기관별 최대 100건의 검색 결과 표시
- 한 번 조회한 검색 목록은 컴퓨터에 저장하여 같은 검색어를 다시 찾을 때 API 호출 없이 즉시 표시하고, `API갱신` 버튼으로 저장 목록을 무시한 새 API 호출 지원
- 통합 결과에 조회 기관 표시
- 법령검색·키워드검색·중앙부처 질의회신·법령해석례·판례검색의 검색창·검색결과·본문을 같은 좌우 구조와 검색결과 약 26%·본문 약 74% 비율로 표시. 분할선에 마우스를 올리면 좌우 크기조절 커서와 강조색이 나타나며 드래그 중에는 더 진하게 표시
- 검색결과 표는 본문보다 작은 9pt 글꼴 사용
- 검색결과 한 줄 행은 약 26~28px로 촘촘하게 표시하고, 명칭·조문이 줄바꿈될 때만 해당 행을 자동으로 두 줄 높이로 확장
- 여러 검색어의 결과 안건명·상세 본문 일치 부분 음영 강조
- 중앙부처 질의회신·법령해석례·판례는 결과를 더블클릭해 상세 본문을 오른쪽
  분할창으로 조회하고, 본문 머리말의 작은 `×`로 분할창 닫기
- 본문 API 미제공 기관(재정경제부·국세청) 자동 안내
- 질의요지, 회답, 이유, 관련법령 표시
- 본문 클립보드 복사
- 본문 마우스 드래그 및 키보드 텍스트 선택
- 본문 내부 검색어 전체 강조, 일치 개수 표시 및 이전·다음 이동
- 조문 목차 영역은 본문이 있을 때만 표시되며 내부 분할선을 드래그해 너비 조절 가능
- 법령검색·직접검색·연관법령의 상단 기능 설명 문구 드래그 선택 및 복사
- 맑은 고딕 본문, 굵은 진한 남색 법령 제목과 SVG 앱 아이콘 적용
- 법령 본문의 `편·장·절·관`과 `제○조(제목)`은 굵은 진한 남색으로 구분하고 `① → 1. → 가.` 계층은 단계별 내어쓰기
- `○`, `O`, `ο`, `Ο`, `ㅇ`, `-`, `•`, `1)` 등의 일반 글머리표 내어쓰기

## 키워드검색 두 기능의 차이

- `직접검색`: 키워드가 직접 포함된 법령·행정규칙의 조문 또는 별표·서식을 찾으며, 키워드가 검색되는 모든 조문을 표시합니다.
- `연관법령`: 키워드와 연관성이 높은 법령·행정규칙 조문을 추천하고, 선택한 해당 조문의 실제 본문까지 추가 조회합니다.
